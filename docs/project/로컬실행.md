# 로컬 실행 (Docker)

> 데모 서버(API · DB · 데모 페이지)를 각자 PC에서 띄우는 방법. 대시보드는 [대시보드_실행기.md](대시보드_실행기.md), 데이터 구성은 [data/README.md](../../data/README.md).

## 1. 데이터 준비 (한 번)

드라이브 `msrs_project/exports/msrs_demo_data.zip`(264MB) 하나를 받아 **저장소 폴더에 그대로** 푼다. `data/` 아래에 이렇게 들어간다 (모두 git 제외 대상).

| 경로 | 내용 |
|---|---|
| `data/dev_subset/` | 개발용 하위 집합: 상품 1,990 · 고객 6,000 · 이벤트 30,255 · 이미지 |
| `data/embeddings/v2/` | 상품 임베딩(텍스트 · 이미지 256차원), 질의 변환 PCA, `has_image.npy` |
| `data/models/ume/` | UME 가중치 (`hm_test_pca`, `amazon_test_pca`) |

## 2. 처음 실행

```bash
docker compose up -d --build
# 로그에 "Application startup complete"가 나올 때까지 대기 (첫 실행은 검색 모델 약 860MB 다운로드)
docker compose exec api python -m scripts.load_dev_subset --data /data/dev_subset --embeddings /data/embeddings/v2
docker compose exec api python -m scripts.register_ume --activate     # UME를 운영 추천 모델로 (#24 머지 후)
```

- Windows Git Bash에서는 경로가 바뀌지 않게 명령 앞에 `MSYS_NO_PATHCONV=1`을 붙인다.
- 데모 페이지 http://localhost:8000/app/ · API 문서 http://localhost:8000/docs

## 3. 검색 모델 캐시와 오프라인 시작

- 검색 모델(MiniLM · Marqo · 토크나이저)은 처음 한 번만 받아 `hf_cache` 볼륨에 저장된다. `docker compose down`, 이미지 재빌드 후에도 유지 (`down -v`만 삭제).
- 기본(`HF_HUB_OFFLINE=0`)은 시작할 때 Hugging Face에 최신 여부를 확인하고 저장된 모델을 쓴다. 대부분 환경은 이대로 충분하다.

### 백신이 HTTPS를 검사하는 PC (예: Avast 웹 실드)

증상: `docker compose build`나 첫 시작에서 `SSL: CERTIFICATE_VERIFY_FAILED`. 백신이 HTTPS를 자체 인증서로 바꿔 끼우는데 컨테이너는 그 인증서를 모른다.

1. 첫 빌드 · 첫 시작(모델 다운로드) 동안만 백신의 HTTPS 검사를 끈다.
2. 시작 로그에 `Application startup complete`가 나오면 다시 켠다.
3. 저장소 폴더 `.env`(없으면 `.env.example`을 복사)에 `HF_HUB_OFFLINE=1` → 이후 시작은 인터넷 확인 없이 저장된 모델 사용.
4. 모델을 바꾸거나 `down -v`로 캐시를 지웠다면 `HF_HUB_OFFLINE=0`으로 되돌려 1번부터.

### 검증 기록 (2026-10-30, Windows · Docker Desktop · Avast)

| 단계 | 결과 |
|---|---|
| HTTPS 검사 끈 상태로 `up -d --build` | 55초 후 시작, `hf_cache`에 모델 2종 + 토크나이저 863MB 저장 |
| HTTPS 검사 다시 켬 | 컨테이너에서 huggingface.co HTTPS 연결 실패 확인 (네트워크 차단과 같은 상태) |
| `.env`에 `HF_HUB_OFFLINE=1` → `down` → `up -d` (컨테이너 새로 생성) | 8초 만에 시작, 재다운로드 없음 |
| `POST /search` q="검은색 원피스" | `query_en: black dress`, 원피스 결과 정상 |

수정 전에는 Marqo 텍스트 토크나이저를 첫 검색 때 받아서, 오프라인 모드에서 텍스트 검색이 500 오류였다 → 인코더 생성 시 함께 받도록 수정.
